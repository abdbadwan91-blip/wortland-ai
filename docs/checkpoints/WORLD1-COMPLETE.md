# World 1 — complete vertical slice

## Structure
World 1 is now a coherent four-stage adventure:
1. Zuhause / Home — greetings and naming home objects.
2. Im Café / Café — polite food and drink ordering.
3. In der Schule / School — understand and answer simple instructions.
4. Dorf-Challenge / Village Boss — combines all three contexts.

## Visual layer
- Original stylized 3D WortLand visual language.
- Layered toy-like map nodes with gloss, extrusion, contact shadows and tactile press feedback.
- Dedicated home/café/school/boss icon identity.
- 3D HUD-style World 1 banner with 1–4 progress.
- Dimensional stage cards with mission copy and reward preview.

## Reward plan
Normal stages scale XP/coins. Stage 4 is the World 1 boss with a larger reward specification and chest marker.

## Functional integration
- Existing map click and lock states preserved.
- Existing gameplay modes remain the execution engine.
- Existing map persistence schema is unchanged.
- Stage 4 continues to use the established boss/master mission routing.
- Completing stage 4 unlocks stage 5 through the existing map progression.

## Art pipeline remaining for production asset quality
The generated art direction is the visual target. Production implementation should progressively replace emoji/painted placeholders with optimized original transparent WebP/AVIF character and landmark renders while keeping this interaction layer.
