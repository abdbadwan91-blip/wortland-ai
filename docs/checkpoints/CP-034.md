# CP-034 — Stage Progression Integrity

Status: preview candidate

## Core fixes
- A replayed/older level can no longer unlock the current journey stage by mistake.
- Map advancement is now bound to the level that was actually played.
- Passing a journey challenge returns the learner to the newly unlocked Journey Stage instead of chaining unrelated game modes.
- Journey missions now rotate by level and topic, so every topic at a level does not force the same game.
- Manual game selection remains available.

## Intended loop
Journey Stage → Topic → Varied Mission → Results → Next Journey Stage

- Built from CP-033.
- No merge to main.
